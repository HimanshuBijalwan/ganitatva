# Ganitatva · गणितत्त्व

**The essence of mathematics — an interactive intuition engine for math, logic, algorithms and physics.**

Runs on Android · iOS · macOS · Windows · Linux from a single codebase.

> Most people don't find math hard. They find **symbol-first teaching** hard.
> Ganitatva teaches every idea as something you can **touch and move** before it becomes a symbol.

**Hard rule:** no concept ships without a widget the learner can manipulate.
